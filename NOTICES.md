## gitleaks (regex bank derivation, v2.0 P1 #2)

- **Project:** `gitleaks/gitleaks`
- **Upstream:** https://github.com/gitleaks/gitleaks
- **License:** MIT
- **Adopted as:** `core/hardcoded-credential-refusal/templates/credential-regex-bank.txt`.
  The 8 default credential-detection regexes (AWS access key, GitHub PAT, Stripe
  sk_live, OpenAI key, Slack bot, JWT, RSA private-key, high-entropy hex) are
  derived from the gitleaks default config family. We do not vendor gitleaks
  source or binaries; only the regex patterns are adapted into a TSV under
  the same MIT terms as the upstream project.

## Anthropic Claude Code sandbox runtime (v2.0 Top-5 #5)

- **Project:** Claude Code sandbox primitive (vendor-released 2025-10-19)
- **License:** Anthropic terms (vendor-internal); not vendored.
- **Adopted as:** configuration target of `core/sandbox-default-on/install-flag.sh`.
  We do not bundle the runtime; we ship an installer flag that flips
  `~/.claude/settings.json` `permissions.defaultMode: "sandbox"`. Operators bring
  their own Claude Code install. Charter §2.4-bis tracker entry (i) records the
  vendor-coordination dependency.
